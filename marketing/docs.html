Getting started

Install KALKI from the download page and open it. A setup guide opens the first time and takes about three minutes:

  1. About you: your name, how KALKI addresses you, and whether to use this PC's location for the weather.
  2. AI brain: pick a service. Each has numbered steps, a button to the right page, and a real test.
  3. Voice: hear the voices and choose how KALKI listens.
  4. Connect apps: optional Google Calendar, Spotify, Gmail, Telegram and GitHub.
  5. Your day: start with Windows, a morning briefing, screen time and a desktop companion.

Every step can be skipped and changed later in Settings.

Voice

Open voice mode with the microphone in the top bar or Ctrl+Shift+V, and just talk. KALKI notices when you stop, answers out loud and listens again. Start talking while it speaks and it stops to listen. The conversation is saved with your chats.

  • Speech to text uses Groq Whisper when you have a Groq key (best for Hindi and Hinglish), otherwise OpenAI Whisper or Google's free recognition.
  • The first time, Windows asks whether KALKI may use the microphone. Allow it.
  • Hands-free: say "Hey KALKI, open Spotify" from across the room, with the screen off. Choose "Hands-free" under Settings, Voice, Listening. A Groq key makes it more accurate: doubtful matches are double-checked, and your command is written down word for word.
  • Savage mode (Settings, Profile) makes KALKI blunt and free to swear, and it roasts insults back in your language.

AI services and keys

KALKI needs one AI service to answer questions. Keys are encrypted with Windows' own protection (DPAPI) and stored only on your PC.

Google Gemini (free)

Open aistudio.google.com/apikey, sign in, press "Create API key" and copy the key starting with AIza.

Groq (free, fastest)

Open console.groq.com/keys, press "Create API Key", and copy the key starting with gsk_ straight away; it's only shown once. A Groq key also gives voice mode its best speech recognition.

OpenAI and Anthropic (paid)

Create a key at platform.openai.com/api-keys (starts sk-) or console.anthropic.com (starts sk-ant-). Both need credit on the account.

Ollama (offline)

Install Ollama, run ollama pull llama3.2 in a terminal, and KALKI finds it automatically. Nothing leaves your PC.

Connected apps

Gmail

Turn on 2-Step Verification for your Google account, open App passwords, create one named KALKI, and paste the 16 letters with your address. For other mail services, set the IMAP server in Settings, Integrations.

Telegram

Message @BotFather, send /newbot, and copy the token. Get your numeric ID from @userinfobot so only you can use the bot.

GitHub

Create a classic token at github.com/settings/tokens with only the notifications scope.

Google Calendar and Spotify

Settings, Integrations, then Connect. A guided window opens for each.

Music without Spotify

Apple Music and YouTube Music work without setup. Apple Music starts playing once something has been played in it before; otherwise it opens and asks you to press play.

Your day

  • Morning briefing: the first time KALKI starts or your PC wakes each day, once you're at the keyboard, it reads your calendar, reminders, tasks and weather. Choose the sections in Settings, Briefing.
  • Weather: turn on "Use this PC's location". Windows finds the PC with GPS or Wi-Fi; your IP address is never used.
  • Focus sessions: 1 to 240 minutes, kept through restarts, with daily and weekly totals. Non-urgent spoken alerts wait until it ends.
  • Screen time: off until you turn it on. App names and minutes only, a retention limit, and one-click delete.

Security check-up

KALKI isn't an antivirus. It works with Windows Defender: it shows Defender's real status, checks files with it, and judges results by Defender's own exit codes. Its own checks explain why something looks suspicious, such as a file named invoice.pdf.exe. A file another program is using shows "couldn't scan", never "clean". Quarantined files are encrypted and can be restored exactly.

See Security for the defensive tools.

Privacy and your data

  • Your data lives in %APPDATA%\KALKI: the database, settings, and the encrypted vault.
  • Your questions go to the AI service you chose. Nothing else is sent unless you connect an app.
  • Consequential actions (sending, deleting, running commands) always wait for your approval.
  • Backups: Settings, Backup. A copy of the current data is kept before any restore.

Troubleshooting

KALKI doesn't speak

Open the Windows Volume mixer and make sure KALKI_Server isn't at 0 or muted. Windows remembers this per app, even after reinstalling. KALKI now turns its own volume back up by itself; switch that off in Settings, Voice. If the natural voice service fails, KALKI uses the Windows voice instead.

Voice mode says the microphone is blocked

Windows Settings, Privacy & security, Microphone: turn on microphone access and "Let desktop apps access your microphone".

Weather says "not set up"

Turn on "Use this PC's location" and allow location in Windows Settings, Privacy & security, Location.

Windows says the app is from an unknown publisher

KALKI isn't code-signed yet. Choose "More info", then "Run anyway". You can check the file against the checksum on the release page first.

Run or build from source

git clone https://github.com/Maher-Bhatt/KALKI.git
cd KALKI\app
python -m pip install -r requirements.txt
python main_app.py

Run the tests from the repository folder with python -m pytest tests. To build the Windows installer, install Inno Setup and run python app\build_tools\build_installer.py.
