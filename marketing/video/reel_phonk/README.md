# KALKI phonk Reel

A 16-second, 150 BPM glitch edit with an original phonk track. Everything in it was made for
KALKI, music included, so you can post it anywhere with no copyright claims.

| File | What it is |
|---|---|
| `kalki_reel_phonk.mp4` | **Post this one.** The Reel with the music. |
| `kalki_reel_phonk_cover.png` | Cover image ("IT ROASTS 💀"). |
| `kalki_reel_phonk_silent.mp4` | The same edit with no audio, for CapCut. |
| `kalki_phonk_track.wav` | The music on its own (16 s), e.g. to reuse as your Reel's "original audio". |

## The edit
| Time | What happens |
|---|---|
| 0:00 | A typewriter on black: "my PC used to be boring" … "until I installed this", over a filtered cowbell melody |
| 0:02.5 | A deep, slowed-down "Hey KALKI" (KALKI's own voice), then a moment of silence |
| 0:03.2 | **Drop 1:** invert flash, distorted 808 and drums. "IT TALKS", "IT ROASTS 💀", then one feature per beat |
| 0:06.4 | Cuts twice per beat: calendar, tasks, answers, focus, any AI, Defender, voice |
| 0:08 | Zoom out: "ALL. IN. ONE. APP." with a snare roll into a silent gap |
| 0:09.6 | **Drop 2:** strobe and harder bells: "FREE.", "OFFLINE MODE", "OPEN SOURCE", "NO CAP 🥶" |
| 0:11.2 | "JUST SAY HEY KALKI" with the vocal again |
| 0:12.8 | **Logo hit:** KALKI, "free AI assistant for Windows", "LINK IN BIO", then a tape stop |
