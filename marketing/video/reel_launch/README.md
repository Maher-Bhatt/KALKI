# KALKI launch Reel

A 20-second motion-graphics launch reel in the "code-built launch video" style of the viral
Claude Opus 5.5 videos. KALKI's interface is rebuilt in code and animated frame by frame, and
the music is an original 120 BPM future-house track with sound effects on every pop, card and
keystroke. It is free to post anywhere, with no copyright claims.

| File | What it is |
|---|---|
| `kalki_reel_launch.mp4` | **Post this one** (Reels, Shorts, TikTok, X). 1080×1920, 20 s, with music. |
| `kalki_reel_launch_cover.png` | Cover ("Just talk." with the voice orb). |
| `kalki_reel_launch_silent.mp4` | No audio, if you want to add your own sound in CapCut. |
| `kalki_launch_track.wav` | The music on its own. |

## Scene by scene
| Time | Scene |
|---|---|
| 0:00 | **Hook:** a glowing orb, "What if your PC could *talk back*?" (the music builds) |
| 0:02 | **Drop:** "Just talk." The orb pulses with sound rings, then a voice conversation types out |
| 0:05 | "Your day, *briefed*." Weather, calendar, tasks and reminder cards fly in on the beat; a task gets ticked |
| 0:08 | "Say it. *Done.*" The command bar types "play some music" (Now Playing drops in), then "open WhatsApp" |
| 0:10 | **Break:** "This is KALKI." The real app swings in, in a Windows 11 window, with a light sweep |
| 0:12 | **Drop 2:** "Everything you need." Six feature tiles pop in on the half beats |
| 0:14 | "And if you're rude…" Savage mode roasts "bro you're kinda useless ngl" 💀 |
| 0:16 | Free. Open source. Your data stays on your PC. Each one ticked on the beat |
| 0:18 | The logo draws itself, "KALKI · Your AI assistant for Windows · Free · link in bio" |
