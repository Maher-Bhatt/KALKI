🛡️ SHIELDCORE ARCHITECTURE

Shannon Entropy & Quarantine Vault

Standard antiviruses rely on signature databases that go stale within 48 hours. ShieldCore employs mathematical Shannon entropy scoring:

H(X) = - Σ P(x_i) × log_2(P(x_i))

When an unknown executable exhibits entropy exceeding 7.2 (indicating packed malware or polymorphic encryption), ShieldCore isolates it in an AES-256 encrypted quarantine vault tied to your Windows DPAPI machine key before execution can occur.

Quarantine Vault Guarantees

  • Zero Execution Risk: Encrypted with AES-256-GCM + DPAPI, stripping executable permissions.
  • Local Loopback Only: No virus samples or telemetry transmitted to external cloud servers.
  • One-Click Remediation: Safely shred quarantined threats with DoD 5220.22-M 3-pass overwrite.
  • Audit Trail: Every scan event is logged to %APPDATA%\KALKI\logs\security.jsonl.
