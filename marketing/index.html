Quick Start Guide

KALKI is designed to run locally on your workstation with no mandatory cloud accounts. You can run 100% offline using Ollama, or connect API keys in Settings.

# 1. Clone repository
git clone https://github.com/Maher-Bhatt/KALKI.git

# 2. Set up virtual environment
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Install dependencies & launch
pip install -r app/requirements.txt
python app/main_app.py

Security & Privacy Model

The server binds strictly to 127.0.0.1 and requires an installation-specific X-KALKI-Token for privileged API requests. Browser origin checks prevent arbitrary websites from contacting local endpoints.

  • Hardware-Bound Memory: Encrypted using Windows DPAPI (win32crypt.CryptProtectData) with machine-keyed AES-256 fallback.
  • SSRF Protection: Blocks access to private IP ranges and cloud metadata endpoints, with whitelist support for NAT64 translation (64:ff9b::/96).
  • Attitude Enforcement: Sustained abusive language streaks trigger immediate physical workstation locking via native LockWorkStation().
