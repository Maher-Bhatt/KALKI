Linux and macOS

Chat, tasks, notes and voice work. Windows-only parts (Defender, app launching, location) are switched off.

Run from source

Every release lists its SHA-256 checksums. The in-app updater only installs files from this GitHub repository and checks them first.

After you install

Open KALKI

The setup guide opens by itself the first time.

Pick an AI

Google Gemini and Groq are free. The guide shows exactly where to get a key and tests it.

Allow the microphone

For voice mode, allow it when Windows asks. You can always type instead.

Say "Hey KALKI"

Or try "brief me", "play some music" or "remind me to stretch in 30 minutes".

What you need

SystemWindows 10 or 11, 64-bit. 4 GB of RAM; 8 GB or more for offline AI with Ollama.
DiskAbout 900 MB.
InternetFor AI answers (unless you use Ollama), the natural voice, weather and connected apps.
Windows SmartScreenKALKI isn't code-signed yet, so Windows may say it's from an unknown publisher. Choose "More info", then "Run anyway". You can check the file against the checksum on the release page first.
